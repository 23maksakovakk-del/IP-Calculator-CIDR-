# 🌐 IP Calculator (CIDR) — быстрый расчёт подсетей для сетевых администраторов

> «IP-адрес, маска, сеть, широковещательный адрес — всё в одном инструменте»

**IP Calculator (CIDR)** — это набор консольных утилит для расчёта параметров IPv4-подсетей в формате CIDR.  
Программа принимает на вход IP-адрес и префикс (например, `192.168.1.0/24`) и выводит всю необходимую информацию: сетевой адрес, широковещательный адрес, маску, диапазон хостов, количество хостов и многое другое.

## 🚀 Особенности
- 📋 Поддержка IPv4 и IPv6 (где реализовано).
- 🔢 Расчёт сетевого адреса, широковещательного адреса, маски подсети.
- 📊 Вывод диапазона доступных хостов.
- 📈 Подсчёт количества хостов в подсети.
- 🎨 Цветной вывод в терминале.
- 📤 Экспорт результатов в JSON и текстовый файл.
- 🧠 Поддержка как десятичной, так и двоичной маски.
- 🔄 Обработка как CIDR-нотации (`/24`), так и полной маски (`255.255.255.0`).
- ⚡ Работа с большими подсетями (до /0).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python ip_calculator.py 192.168.1.0/24` |
| Go         | стандартная библиотека               | `go run ip_calculator.go 192.168.1.0/24`|
| JavaScript | Node.js, `fs`, `readline`            | `node ip_calculator.js 192.168.1.0/24`  |
| Java       | стандартная библиотека               | `javac ip_calculator.java && java ip_calculator 192.168.1.0/24` |
| C#         | .NET (или mono)                      | `dotnet run 192.168.1.0/24`            |
| Rust       | `std::net`, `serde`, `serde_json`    | `cargo run -- 192.168.1.0/24`          |
| Ruby       | `ipaddr` (встроенный)                | `ruby ip_calculator.rb 192.168.1.0/24` |
| PHP        | стандартная библиотека               | `php ip_calculator.php 192.168.1.0/24` |
